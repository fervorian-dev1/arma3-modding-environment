## Easy optimizations

- Removed native convoy cohesion's repeated full-world vehicle scans, pairwise distance scans, pace/recovery RPCs and competing AI orders.
- Extra ground escorts no longer have an independent repeated follow controller or an extra roadside spawn/search. Native route state is shared/reused for their placement.
- Moving global marker still updates every2seconds when position changes; stationary marker metadata is not repeatedly broadcast. Forced-known OBJECT task destination is bound once and only rebound when the subject changes (such as unloading native Money/Supplies cargo). Previously the task was republished every2seconds even though an object-bound task follows itself.
- Oswald migration runs immediately after server initialization, then every30seconds instead of5, scanning only the actual Watch category rather than every JNA category. Initial/default-free/unlimited prevention and finite-stock preservation retained.
- Isotope fallback death watchdog scans every5seconds rather than every0.5. MPKilled's normal queued release still processes on the existing0.5second worker. Captured/completed isotope trucks remain watched; no loss of the later-destruction behavior.

No graphics/view-distance, global AI mod settings, campaign population or faction/map/territory edits. These reduce addon scheduler/network overhead; there is **no measured FPS uplift claim**.
