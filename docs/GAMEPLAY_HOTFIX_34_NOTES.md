# Gameplay hotfixes — companion v3.4, 2026-11-08

## Requests and implemented fixes

1. **Oswald available free in arsenal.** Installed Ultimate config sorting collects all public scope2 Watch items, and basic Watches become initial/unlimited equipment; scopeArsenal0 alone did not prevent that. Oswald now has scope1 (still a real inventory/Watch item) and an Ultimate forbidden-item entry preventing unlimited unlocks and crate generation. Server maintenance removes only this class from allWatches/unlockedWatches/basic loot and removes an existing JNA unlimited(-1) entry. Finite deposited bracelets and carried/equipped items are preserved. Mystic's paid purchase path remains functional. No removal of other Watches/gear and no player-inventory confiscation.

2. **Revived players still see downed prompt and R respawns them.** Ultimate's native unconscious key handler dispatches R without checking recovery. PiR can finish its physical recovery while the independent native incapacitated flag/handler survives. One configuration entry redirects the final SCRT key function to a guard, retaining the installed original for genuinely downed/dead players. Physical detection checks engine/ACE incapacity and PiR injury animations; unconsciousoutprone is a recovery animation, not a new down episode. R cannot dispatch respawn while physically recovered. A single owner-local monitor waits2seconds of consciousness, clears the stale native incapacitated flag and removes exactly respawnMenu's KeyDown ID. It leaves numeric sentinel-1 so the original native unconscious script can finish its own countdown/UI cleanup without an undefined global. No healing, immunity, syringe consumption, forced respawn or removal of unrelated handlers. Native prompt rendering stops when its original loop exits. Existing PiR automatic syringe recovery remains.

3. **Convoy objectives always marked.** A trusted server queue starts one tracker per native objective; debug convoys use it too. Global marker and forced-known task destination update every2seconds, independent of spotting/driver knowledge and with normal JIP replication. Original native objective marker thread is skipped to avoid its delayed/stale60second duplicate; escort spotting is unchanged. Debug tracker reuses its existing position-marker name. Native Money/Supplies logistics cargo is remembered while aboard and remains the marked subject after unloading. Markers end on destroyed truck or terminal task rather than persisting as clutter forever.

4. **Convoy spawn collisions/explosions.** New shared ground-spawn search uses classname-scaled clearance (8–24m), flat dry ground, roads within80m, nearby vehicle/person rejection, terrain obstacle checks and actual findEmptyPosition. It searches within180m of the route seed, without an unsafe seed-coordinate fallback. Addon debug/response/escort ground vehicles use it. The installed native worker gets a version-checked position/orientation insertion before vehicle creation, so its objective, lead and escort vehicles use clear roadside areas too. Missing escort placement is skipped; failed objective placement removes partial units/vehicles, fails/deletes the native task and releases the active-convoy gate. Original route/completion/rewards, including70,000 Money minimum, remain. This reduces spawn clipping; it cannot guarantee every mod model's physics or later AI driving collision will never fail.

5. **Never unarmed convoy helicopter companions.** Removed the explicit spotter setVehicleAmmo0 path. Convoy cover, response insertions and tracking spotters select the existing validated same-side door-gun pool; absent armed candidates are skipped, not replaced with unarmed scouts. Kinetic-only/non-HE restriction remains. Sanitizer now requires actual nonzero ammunition AND a living turret gunner with a compatible retained weapon. Gunless/uncrewed failed spawns are removed; escort/pursuit helicopters that lose their gunner/ammunition stop following and are ordered away rather than remaining as unarmed companions. No unlimited ammo added and no global faction/AI changes.
